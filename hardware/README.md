# Hardware

Ordner fuer Kaufberatungen und Hardware-Notizen, die weder in die
Wissensdatenbank (Alltagserklaerungen) noch in die Agentenmatrix
(Bestand) gehoeren.

## Was hier liegt

- `laptops-fuer-lokale-modelle.md` - welche Laptops eignen sich fuer
  den Betrieb lokaler KI-Modelle. Stand 2026-07-24.

## Was hierhin gehoert

- Kaufempfehlungen fuer Rechner, Server, Peripherie
- Preisstaende zu Hardware, sofern sie fuer Entscheidungen relevant sind
- Vergleiche zwischen konkreten Geraeten

## Was hier nicht hingehoert

- Bestandsbeschreibung der laufenden Server -> `Agentenmatrix.md`
- Alltagsbegriffe erklaert -> `wissensdatenbank/glossar.md`
- Fahrplaene und Entscheidungen -> `wissensdatenbank/entscheidungen/`
