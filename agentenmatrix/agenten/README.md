# Detailseiten der Agenten

Dieser Ordner enthaelt fuer jeden Agenten auf Sarahs Servern eine
eigene Detailseite. Die zentrale Uebersicht steht weiterhin in
`../sarahs-agenten.md`.

## Aufbau einer Detailseite

Jede Datei folgt demselben Schema:

- **Kopfdaten** - Server, Linux-User, Port, Modell, Owner, VNC.
- **Skills / Faehigkeiten** - wofuer der Agent zustaendig ist, was er
  konkret loesen kann.
- **Werkzeuge und Zugaenge** - Telegram, Memory, Perplexity, Repos.
- **SOUL.md** - vollstaendiger Text seiner Charakterdefinition.
- **AGENTS.md** - vollstaendiger Text seiner Arbeitsanweisung.
- **Notizen und Aenderungen** - Historie, offene Punkte.

## Pflegeregel

- Aenderungen an SOUL.md oder AGENTS.md werden hier gespiegelt.
- Skills-Aenderungen bei Aufgabenverschiebungen direkt eintragen.
- Zustand (aktiv/haengend/pausiert) wird in der Uebersicht gepflegt,
  nicht dupliziert.
