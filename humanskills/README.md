# Humanskills

Sarahs Nachschlagewerk fuer den Umgang mit ihren Agenten.

Die Wissensdatenbank erklaert, **was Dinge sind**. Humanskills erklaert,
**wie du sie im Alltag benutzt** - welche Befehle du hast, wann du sie
nutzt, welche Gewohnheiten helfen.

## Inhalt

- `slash-befehle.md` - Befehle, die mit `/` beginnen (`/new`, `/status`
  usw.), wozu sie da sind, wann welcher passt.
- `wann-neue-session.md` - Faustregeln, wann es Sinn macht, eine neue
  Session zu starten, statt in der alten weiterzuarbeiten.
- `agenten-ansprechen.md` - wie du die Agenten am effektivsten
  ansprichst, damit sie gute Antworten geben.

## Aufbau

Jede Datei enthaelt kurze, praktische Anleitungen. Ziel: Sarah wird
mit den Werkzeugen souveraener, ohne Techniker zu werden.

Die Liste wird erweitert, wenn Sarah neue Fragen stellt oder neue
Alltags-Situationen auftauchen.
